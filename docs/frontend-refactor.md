# Frontend screenshots

The Next.js web app in [`frontend/web`](../frontend/web/README.md), shown with the sample bank project.

## What the app does

- Sign up, sign in, and sign out, with Neon Auth or API accounts.
- Saved projects, the sample bank, file uploads with drag-and-drop, file removal, and project deletion.
- A dependency map of COPY, CALL, and PERFORM references, with links back to the original source.
- COBOL and Python side by side, with syntax highlighting, search, line wrapping, and a full-screen view. The Python is editable.
- Verification results, AI review findings, and review notes grouped by task.
- Export previews and downloads: Python files (with your edits), the original COBOL, and the audit CSV.
- Batch conversion of standalone programs, without saving a project.
- Light, dark, and system themes; keyboard focus; reduced motion; mobile layouts.
