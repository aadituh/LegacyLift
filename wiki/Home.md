# What is LegacyLift?
LegacyLift is an AI-assisted pipeline that helps organizations modernize outdated COBOL by uploading programs, mapping dependencies, converting them to Python drafts, and checking that the Python prints the same results as GnuCOBOL.

# How Does LegacyLift Work?
LegacyLift allows you to:
* Upload COBOL programs, copybooks, and data files as one project (up to ten files)
* Analyze COPY, CALL, and PERFORM links so you see how the batch fits together
* Convert each program to Python for human review, with TODO notes where the converter cannot yet handle a line
* Verify by running the original COBOL and the generated Python side by side in an isolated runner
* Load the built-in October close demo to walk through a realistic month-end bank batch
