# Convert Standalone Programs
Convert up to five COBOL programs without creating a project.

## Before you start
* Sign in.
* Have 1 to 5 `.cbl` or `.cob` files ready. Each must be UTF-8 text of at most 200 KB.

## Steps
1. Click **Batch conversion** in the main navigation.
2. Click **Choose COBOL files** and select your files. To try the page without files, click **Load small sample**.
3. Check that the file names appear in the list on the left.
4. Click **Convert files**.
5. Select a program in that list to see its COBOL beside the Python draft.
6. Read **Lines to review**. Each entry is a COBOL line the converter did not translate.
7. Under **Downloads**, click **Download .py** for each program you want to keep.

## Good to know
* Download before you refresh or close the tab. Batch results are not saved.
* The download contains the Python as it appears on the page, including your edits.
* To verify a program against the original COBOL, add it to a project instead (see [[Upload Project Files|Upload-Project-Files]]).
