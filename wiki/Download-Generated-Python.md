# Download Generated Python
## Steps
1. Complete a conversion run (project or batch).  
2. Open **Export**.  
3. Select the convert run (or batch download id).  
4. Download each generated `.py` file for offline review.  
5. Optionally download `audit-report.csv` after verification for a full project record.

Generated Python is a draft for human review before production use.
