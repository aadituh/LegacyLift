# Download Generated Python
## Steps
1. Complete a conversion run (project or batch).  
2. Open **Export**.  
3. Select the convert run (or batch download id).  
4. Download each generated `.py` file for offline review.  
5. Optionally download `audit-report.csv` after verification for a full project record.

Generated Python is a draft for human review before production use.

## Notes from the built Export screen

* **Preview** opens the Python, the original COBOL, or the audit report before the download.
* **Download .py** saves the Python shown in the tab, including edits made on Convert. Those edits are discarded on refresh, sign-out, or another conversion.
* **Download .csv** stays off until the project has been verified. The CSV describes the saved draft, not unsaved edits.
* Batch conversion does not use this download list.
