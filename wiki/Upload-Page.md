# Upload Page
Welcome to the **Upload Page** guide for LegacyLift!

***
* Users land here to create a project, open a saved project, or load the demo.  
* Choose **Project** mode to save files on the API (batch mode converts in the browser and is not saved).  
* Upload lists every project stored for the account. **Open** loads that project and its last Python, then can switch to Convert. **Remove** deletes one project; clear can empty the list.  
* The project id stays in the browser tab so a refresh reopens the same project.

## What you can do here
* Enter a project name and choose **Create project** (empty name shows “Enter a project name.”).  
* Upload `.cbl` / `.cob`, `.cpy`, and `.dat` files subject to the upload checks.  
* See each added file by name and kind; batch files stay out of the open project when using project mode.

***

Driver path from the design presentation: **Upload = Input + project selection** → then Convert → Export.
